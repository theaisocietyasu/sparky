# SparkyAI roadmap

SparkyAI is an assistant for ASU students and their organizations, on Discord first and the web later. Platform holds knowledge, live ASU queries and linked accounts. Sparky keeps its own conversations, confirmations and memories. An open model trained on clean interaction data comes after the evals exist.

The order of work and each phase's checklist are in the master issue [#79 SparkyAI v1.0](https://github.com/theaisocietyasu/sparky/issues/79) and its sub-issues.

| Phase | Goal | Issue |
|---|---|---|
| 3: Ingestion and answers v0.3 | deeper crawls, structural chunks, provenance a citation can use | [#87](https://github.com/theaisocietyasu/sparky/issues/87) |
| 5: Memory v0.5 | personalized discovery and deadlines, admin surface | [#88](https://github.com/theaisocietyasu/sparky/issues/88) |
| 6: Public beta v0.6 | benchmarks, staging and prod, canary releases, alerting | [#89](https://github.com/theaisocietyasu/sparky/issues/89) |
| 7: sparky-model-v0.1 | baseline, staged post-training gated on evals, release | [#90](https://github.com/theaisocietyasu/sparky/issues/90) |
| 8: v1.0 | stable API, documented traits, published evals, university-adapter template | [#91](https://github.com/theaisocietyasu/sparky/issues/91) |

## Out of scope until stated otherwise

GPA or coursework access · browser automation of any kind · university-wide deployment · FERPA claims · one agent per domain · RL before evals exist.
